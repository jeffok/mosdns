# Cold-state 300-domain test, 2026-11-14

ROS DNS cache was flushed before this test; old test-only route states were backed up locally and removed, existing DNS static configuration and production address lists were not deleted. The household DNS cache immediately repopulates as clients query it. The two batches each started a fresh test agent with no prewarm and a fresh route-state file; before each batch agent state reported peer_up=true, zero routes, zero requests. Recursive upstream and clients' caches are outside this test's control. Household DNS was not switched to the test resolver.

See SAMPLING.md for the 300 randomly selected overseas candidates, their reproducibility and geographic limitations. The Tranco list contains infrastructure names; no DNS prefiltering was performed. Batch A and B were each 150 distinct names, tested with concurrency 3, UDP A query (TCP on TC) and, when an A answer existed, HTTPS root GET using the first IPv4 without following redirects.

Results: 299 NOERROR, 1 SERVFAIL; 251 responses contained at least one A record, and 48 NOERROR responses contained no A record. The 251 HTTPS attempts returned 53 2xx, 125 3xx, 43 4xx, 2 5xx, and 28 TLS or connection errors. These are not full website usability checks. All 300 DNS queries used UDP; TC fallback is not exercised by this dataset. DNS query latency p50 1133 ms, p95 2648 ms (nearest rank), maximum 4548 ms; this includes upstream resolution and route confirmation.

The SERVFAIL for tcdnlive.com occurred after 4548 ms and repeated after 4502 ms. Agent log reported ROS route confirmation timeout; state showed a 0.0.0.1/32 route attributed to tcdnlive.com, without ACK. RouterOS BGP input rejects 0.0.0.0/8, while agent eligible() lacks that prefix and Go's IsGlobalUnicast reports true for 0.0.0.1. The precise upstream reason for returning that address was not established. Fix must align special-use validation before selecting/caching an upstream answer; simply skipping advertisement while returning a reserved A as a positive answer is unsafe. Do not replace this failed sample or call it a success.

Afterwards the isolated container was stopped and ACK scheduler disabled; active test BGP routes were zero, test-generated route-state files and temporary domain lists were removed, and household DNS remained 119.29.29.29. No ROS production routing policy was changed. Real GC withdrawal, persistence after abrupt power loss and long-duration reliability remain unaccepted.
