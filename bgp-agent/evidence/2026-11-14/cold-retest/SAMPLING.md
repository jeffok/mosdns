# 300 域名冷缓存测试抽样

- 来源：[Tranco Top 1M](https://tranco-list.eu/top-1m.csv.zip)，使用本机于 2026-11-14 留存的 ZIP，SHA-256 `0c1fb07bca635ab1febe4b3fe52331636801cbf4f831f24497cd638e9d4db84c`；ZIP 内 CSV 时间为 2026-11-13 22:21（ZIP 未包含时区）。
- 选择排名前 10000 条，排除前两次 200 域名清单中的精确名称及去除 `www.` 后同名的域名、`.cn` 和 `.xn--fiqs8s`，并按 `sample-selection.json` 所列关键词排除明显中国品牌；剩余 9487 项。
- 按 ZIP 中原始排序构造候选序列，用 Python `random.Random(202611140301).shuffle()` 打乱，取前 300 项。`sample-selection.json` 保存完整过滤词、种子及每个样本对应的原始排名。
- 样本只使用已有 ZIP 文件和域名字符串筛选，**没有预解析样本域名**。此举避免抽样过程预热本次客户端或路由器 DNS 缓存，但不能保证上游公共 DNS 递归服务器没有缓存。

Tranco 统计受欢迎的域名，名单也包括 CDN、广告、DNS 和 API 域名，不代表这 300 项都是用户直接访问的网页。关键词及域名后缀无法可靠确定企业运营主体或服务器所属国家，因而这些名称是海外服务**候选**，不保证每一项都实际位于境外。未预筛 A 记录也意味着少数名称可能无法解析或没有 A 记录；这类结果必须如实统计，不能替换样本后宣称全部成功。
