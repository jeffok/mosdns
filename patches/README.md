# Selected response provenance for the BGP integration

`mosdns-response-source.patch` is applied to the exact pinned upstream commit by `tools/build-mosdns.sh`. It adds an immutable provenance key to query context and makes fallback carry the value from the response that actually won. It fails to apply if upstream changed. `fallback_route_source_test.go` is copied into the upstream fallback package and tests parallel source selection.

Set `ENABLE_ROS_BGP=1` and `ROS_BGP_CONFIRM_URL=http://<trusted-agent>:9080/confirm`. This mode disables mosdns's response cache because upstream's cache format does not retain the provenance and cannot safely identify a winning global answer after a cache hit. The query pipeline still applies hosts, CN, AI, hard and soft lists and fallback. Global/AI responses are marked; the outer entry sends the selected answer's non-CN, public IPv4s to the agent and sends the original answer only after HTTP 204. Negative/empty/non-global answers do not require confirmation. HTTP errors, invalid public IPv4s and expiration while waiting fail closed; TTL is capped to 300 and reduced by confirmation wait time.

The agent must allow the actual source IP of the mosdns container and must be separately configured to enable `/confirm`. Source IP restrictions are not cryptographic authentication. Do not publish this integration to household routing without separately validating routing isolation, source selection under fallback, restart persistence, actual route expiry, and shared-IP side effects. This patch does not prove first-packet forwarding, bypass client-owned DNS, nor solve global IP routing interference with domestic domains that share an address.

Run `go test -race ./plugin/executable/ros_bgp ./plugin/executable/sequence/fallback` inside the prepared pinned upstream tree. For actual DNS processes, `MOSDNS_IMAGE=mosdns:bgp-tools-local sh tests/bgp-integration.sh` uses a test image with the newly compiled binary and an arm64 mock. See the build instructions before attempting an image deployment.
